# Internet, E-mail e Segurança

## Antes de digitar a senha

- Nome do site **certo** na barra de endereço
- **Cadeado** ao lado do endereço

## Pesquisar no Google

| | |
|---|---|
| `"frase exata"` | Procura a frase inteira |
| `excel -curso` | Tira a palavra "curso" |
| `apostila filetype:pdf` | Só arquivos PDF |

## E-mail

| | |
|---|---|
| **Para** | Quem precisa ler e responder |
| **Cc** | Quem só precisa saber |
| **Cco** | Cópia escondida |

Antes de enviar: o **anexo** está lá? **Destinatário** certo? **Português** ok?

## Senha forte

- 12 caracteres ou mais (uma frase é ótimo)
- **Uma senha diferente** para cada site
- Ative a **verificação em duas etapas** (código no celular)

## Golpes

| | |
|---|---|
| **Mensagem falsa** | Link de "banco" ou "loja": não clique |
| **Falso suporte** | Desligue e ligue no número oficial |
| **Boleto falso** | Confira o nome de quem recebe |
| **WhatsApp clonado** | **Nunca** passe o código do SMS |
| **Vírus em anexo** | Não abra o que não esperava |

## Sinais de e-mail falso

- Pressa: "bloqueio **hoje**!"
- Remetente esquisito
- Erros de português
- "Prezado cliente" em vez do seu nome
- Anexo inesperado ou "Habilitar conteúdo"

> **Passe o mouse no link sem clicar** e veja para onde ele leva. Na dúvida, não clique.

## No trabalho

| | |
|---|---|
| Saiu da mesa | `Win + L` |
| Pendrive desconhecido | Não use |
| Programa pirata | Não instale |
| Wi-Fi público | Nada de banco |
| Backup | Arquivos em 2 lugares |
| Dados de clientes | Sigilo (LGPD) |
