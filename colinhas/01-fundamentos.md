# Fundamentos de Informática

## Hardware x software

| | |
|---|---|
| **Hardware** | O que você toca: monitor, teclado, mouse |
| **Software** | Os programas: Windows, Excel, Chrome |

## Partes do computador

| | |
|---|---|
| **Processador** | O "cérebro": faz tudo funcionar |
| **Memória RAM** | A "mesa": o que está aberto agora. Esvazia ao desligar |
| **SSD / HD** | O "armário": guarda os arquivos de vez |

> Só fica guardado o que você **salvou**!

## Tamanho dos arquivos

| | |
|---|---|
| **KB** | Um texto simples |
| **MB** | Uma foto de celular |
| **GB** | Um filme |
| **TB** | Um HD cheio de fotos e vídeos |

Internet em **Mbps** ÷ 8 = MB por segundo. Ex.: 100 Mbps = uns 12 MB/s.

## Extensões (tipo do arquivo)

| | |
|---|---|
| **.docx** | Texto (Word) |
| **.xlsx** | Planilha (Excel) |
| **.pptx** | Slides (PowerPoint) |
| **.pdf** | Documento para ler/imprimir |
| **.jpg .png** | Imagem |
| **.mp3 .mp4** | Música / vídeo |
| **.zip** | Vários arquivos em um |
| **.exe** | Programa (cuidado: vírus!) |

## Palavras do dia a dia

| | |
|---|---|
| **Backup** | Cópia de segurança |
| **Download** | Baixar da internet |
| **Upload** | Enviar para a internet |
| **Login** | Entrar com usuário e senha |
| **Nuvem** | Arquivos guardados na internet (Drive, OneDrive) |
| **Navegador** | Programa de sites (Chrome, Edge) |
| **Roteador** | Caixinha que espalha a internet |
| **Vírus** | Programa que estraga ou rouba dados |
