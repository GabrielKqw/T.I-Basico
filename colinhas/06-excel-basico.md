# Excel: Primeiros Passos

## A planilha

| | |
|---|---|
| **Coluna** | Letras: A, B, C... |
| **Linha** | Números: 1, 2, 3... |
| **Célula** | Coluna + linha. Ex.: `B3` |
| **Intervalo** | `A1:A10` = de A1 até A10 |
| **Aba** | As folhas lá embaixo |

Texto fica à **esquerda**, número à **direita**. CEP com zero: `'01234-000`

## Contas (sempre comece com =)

| | |
|---|---|
| `=A1+B1` | Somar |
| `=A1-B1` | Subtrair |
| `=A1*2` | Multiplicar |
| `=A1/4` | Dividir |
| `=A1*10%` | 10% de A1 |
| `=(2+3)*4` | Parênteses primeiro |
| `=SOMA(A1:A10)` | Soma de A1 até A10 |

> Separador no Excel em português: **ponto e vírgula** `;`

## Truques que salvam tempo

| | |
|---|---|
| **2 cliques no quadradinho** da célula | Copia a conta até o fim |
| Digite `Jan` e arraste | Fev, Mar, Abr... |
| `$` na célula (`$E$1`) | Trava a célula ao copiar |
| `F4` | Coloca o `$` |
| Coluna com `#####` | 2 cliques na divisa das letras |

## Formatação (Página Inicial)

| | |
|---|---|
| R$ | Número > Moeda |
| % | Número > Porcentagem |
| ,00 | Mais/menos casas decimais |
| Bordas | Grupo Fonte |
| Pincel | Copia só a aparência |
| `Ctrl + 1` | Todas as opções |
| Congelar cabeçalho | Exibir > Congelar Painéis |

## Atalhos (Excel em português)

| | |
|---|---|
| `Ctrl + B` | Salvar |
| `Ctrl + N` | Negrito |
| `Ctrl + Z` | Desfazer |
| `Alt + =` | Soma automática |
| `F2` | Editar célula |
| `Ctrl + ;` | Data de hoje |
| `Ctrl + setas` | Pula até o fim dos dados |
| `Ctrl + Shift + L` | Filtros |
| `Alt + Enter` | Nova linha na célula |
| `Ctrl + P` | Ver antes de imprimir |

## Salvar e imprimir

- PDF: Arquivo > Salvar como > **PDF**
- Não coube? `Ctrl + P` > **Paisagem** + **Ajustar colunas em uma página**
