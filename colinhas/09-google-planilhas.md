# Google Planilhas

**Abrir:** sheets.google.com ou Google Drive > **Novo** > **Planilhas Google**

## Por que usar

- **Grátis** (conta Google)
- **Salva sozinho**
- Abre em **qualquer lugar**, até no celular
- **Várias pessoas** editando juntas
- Abre e salva **.xlsx**

> As fórmulas são **as mesmas do Excel**: `SOMA`, `SE`, `PROCV`, `SOMASE`...

## Excel x Google

| | |
|---|---|
| Salvar | Excel: `Ctrl + B` / Google: sozinho |
| Arquivo fica | Excel: no PC / Google: no Drive |
| Compartilhar | Google: botão **Compartilhar** |

## Compartilhar

| | |
|---|---|
| **Leitor** | Só vê |
| **Comentarista** | Vê e comenta |
| **Editor** | Muda tudo |

> "Qualquer pessoa com o link" = **qualquer um** que receber o link abre. Nunca use com dados de clientes.

## Recursos úteis

| | |
|---|---|
| Arquivo > **Histórico de versões** | Volta atrás e mostra quem mudou |
| Inserir > **Caixa de seleção** | Checklist |
| Inserir > **Menu suspenso** | Lista de opções |
| Formatar > **Formatação condicional** | Cores automáticas |
| Inserir > **Tabela dinâmica** | Resumo automático |
| `Ctrl + /` | Todos os atalhos |

## Só no Google

| | |
|---|---|
| `=GOOGLETRANSLATE(A2;"pt";"en")` | Traduz |
| `=GOOGLEFINANCE("CURRENCY:USDBRL")` | Cotação do dólar |
| `=IMAGE("endereço")` | Imagem na célula |

## Excel para Google

1. Google Drive > **Novo** > **Upload de arquivo**
2. 2 cliques no arquivo > **Abrir com Planilhas Google**

## Google para Excel

**Arquivo** > **Fazer download** > **Microsoft Excel (.xlsx)**
