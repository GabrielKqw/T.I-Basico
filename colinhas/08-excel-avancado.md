# Excel: Recursos Avançados

## Dados organizados

- Cabeçalho na **1ª linha**
- **Uma informação** por coluna
- **Uma linha** por registro
- **Sem linhas em branco** nem células mescladas

## Tabela

| | |
|---|---|
| `Ctrl + Alt + T` | Transforma em Tabela |
| Design da Tabela > Nome | Dar nome (ex.: TabVendas) |
| Linha de Totais | Total automático |

A tabela **cresce sozinha** com as novas linhas.

## Ordenar e filtrar

| | |
|---|---|
| Setinha do cabeçalho | Ordenar e filtrar |
| `Ctrl + Shift + L` | Liga/desliga as setinhas |
| Limpar Filtro | Mostra tudo de novo |

## Ferramentas

| | |
|---|---|
| Dados > **Remover Duplicatas** | Apaga repetidos |
| Dados > **Texto para Colunas** | Separa em colunas |
| `Ctrl + E` | Completa pelo exemplo |
| `Ctrl + U` | Localizar e substituir |
| `Ctrl + Alt + V` | Colar só valores |

## Cores automáticas

Página Inicial > **Formatação Condicional**

| | |
|---|---|
| Realçar Regras | Maior que, menor que... |
| Valores Duplicados | Acha repetidos |
| Primeiros/Últimos | 10 maiores, abaixo da média |
| Barras de Dados | Barrinha na célula |
| Limpar Regras | Tira as cores |

## Lista de opções

Dados > **Validação de Dados** > Permitir: **Lista** > Fonte:

```
Sul;Norte;Sudeste;Nordeste
```

## Gráficos

| | |
|---|---|
| `Alt + F1` | Gráfico rápido |
| Colunas / Barras | Comparar |
| Linhas | Evolução no tempo |
| Pizza | Partes do total (até 5) |

## Tabela Dinâmica

**Inserir > Tabela Dinâmica > OK**, depois arraste:

| | |
|---|---|
| **Linhas** | Vendedor (de cima para baixo) |
| **Colunas** | Região (lado a lado) |
| **Valores** | Valor (o que somar) |
| **Filtros** | Filtro geral |

| | |
|---|---|
| Mudou os dados | Botão direito > **Atualizar** |
| Contar em vez de somar | Configurações do Campo de Valor |
| Datas por mês | Botão direito > Agrupar > Meses |
| Botões de filtro | Inserir Segmentação de Dados |

## Proteger

| | |
|---|---|
| Revisão > Proteger Planilha | Ninguém mexe |
| Arquivo > Informações > Criptografar | Senha para abrir |
