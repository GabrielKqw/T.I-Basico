# ChatGPT para Excel

**Abrir:** chatgpt.com (tem versão gratuita)

## O que pedir

| | |
|---|---|
| Fórmula | "Fórmula para somar as vendas da Ana" |
| Explicação | "O que faz esta fórmula: ..." |
| Erro | "Meu PROCV dá #N/D, por quê?" |
| Planilha | "Que colunas uso num controle de gastos?" |
| Aprender | "Me explique PROCV como se eu fosse iniciante" |

## Pedido bom tem 4 coisas

| | |
|---|---|
| **1. Qual Excel** | "Uso Excel em português" |
| **2. Colunas** | "A = Vendedor, E = Valor, linhas 2 a 500" |
| **3. O que quer** | "O total vendido por vendedor" |
| **4. Onde** | "Na célula H2" |

> Esqueceu o "Excel em português"? A resposta vem em inglês e dá **#NOME?**

## Modelo para copiar

```
Uso Excel em português. Na minha planilha, a coluna [A] tem [X] e a coluna [B] tem [Y], da linha 2 até a [500]. Quero [o que você quer] na célula [H2]. Me dê a fórmula e explique de um jeito simples.
```

## Outros pedidos prontos

```
Explique, para quem está começando, o que esta fórmula faz: [fórmula]
```

```
Esta fórmula dá o erro [#N/D]: [fórmula]. O que pode ser e como arrumo?
```

```
Seja meu professor de Excel. Me explique [PROCV] e me passe 3 exercícios fáceis.
```

## Passo a passo

1. **Explique** a planilha
2. **Copie** a fórmula para a célula
3. **Confira** em 1 ou 2 linhas
4. Deu erro? **Conte** para ele
5. **Peça explicação** para aprender

## Cuidados

| | |
|---|---|
| A IA erra | Sempre confira |
| Dados pessoais | **Nunca** envie (LGPD) |
| Planilha real | Descreva as colunas ou use dados inventados |
| Empresa | Pergunte se pode usar IA |
