# Windows e Atalhos

## Os essenciais

| | |
|---|---|
| `Ctrl + C` | Copiar |
| `Ctrl + V` | Colar |
| `Ctrl + X` | Recortar |
| `Ctrl + Z` | Desfazer |
| `Ctrl + Y` | Refazer |
| `Ctrl + A` | Selecionar tudo |
| `Ctrl + P` | Imprimir |
| `Ctrl + F` | Procurar palavra |
| `Alt + Tab` | Trocar de janela |
| `Alt + F4` | Fechar programa |

> Word/Excel em português: **salvar** = `Ctrl + B`, **negrito** = `Ctrl + N`.

## Tecla Windows

| | |
|---|---|
| `Win` | Menu Iniciar (digite o programa) |
| `Win + E` | Abrir pastas |
| `Win + D` | Mostrar área de trabalho |
| `Win + L` | **Bloquear o PC** |
| `Win + Shift + S` | Print de um pedaço |
| `Win + V` | Últimas coisas copiadas |
| `Win + .` | Emojis |
| `Win + seta` | Janela na metade da tela |

## Arquivos

| | |
|---|---|
| `F2` | Mudar o nome |
| `Delete` | Apagar (lixeira) |
| `Shift + Delete` | **Apaga para sempre!** |
| `Ctrl + clique` | Escolher vários |
| Botão direito > Novo > Pasta | Criar pasta |

## Navegador

| | |
|---|---|
| `Ctrl + T` | Nova aba |
| `Ctrl + W` | Fechar aba |
| `Ctrl + Shift + T` | Reabrir aba fechada |
| `Ctrl + D` | Favoritar |
| `Ctrl + J` | Downloads |
| `Ctrl + +` / `Ctrl + -` | Zoom |

## Deu problema?

| | |
|---|---|
| Programa travou | `Ctrl + Shift + Esc` > Finalizar tarefa |
| PC lento ou estranho | **Reinicie** primeiro |
| Atualizar | Iniciar > "Windows Update" |
| Disco cheio | Iniciar > "Armazenamento" |
